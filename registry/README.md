# Registry listings (to submit after the public release)

- **Official MCP Registry**: `server.json` in the repo root. Publish with `mcp-publisher publish`
  (GitHub login for the `io.github.Open-Cosmic-Software/*` namespace). Requires the npm package
  `nyxmix@0.1.0` to exist and its package.json to contain `"mcpName": "io.github.Open-Cosmic-Software/nyxmix"`.
- **Smithery** (smithery.ai): add the GitHub repo; it is an HTTP server, users run `npx nyxmix` locally.
- **mcp.so**: submit form with repo URL + one-line description from package.json.
- **Agent skill**: `SKILL.md` in the repo root (Claude / ClawHub skill format).
